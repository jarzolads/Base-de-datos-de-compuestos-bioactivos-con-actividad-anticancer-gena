Base de datos primaria integrada con información sistematizada sobre compuestos bioactivos con actividad anticancerígena, que reúne datos de identificación, origen, clasificación, propiedades biológicas, tipo de cáncer asociado, 210 descriptores moleculares, mecanismo de acción reportado y evidencia experimental disponible. Su propósito es organizar y facilitar el análisis comparativo de compuestos con potencial terapéutico en investigación oncológica.
